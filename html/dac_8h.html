◆ calibrate()

unsigned int calibrate ( byte  val)

Cette fonction permet de calibrer les CVs.

La fonction permet d'envoyer exactement 4 volts pour C4 sur CV1. On doit observer 2 volts sur CV2 et 1 volt sur CV3. La valeur est conservée en mémoire dans les paramètres et sert de valeur de référence dans les actions.

Paramètres
valest la valeur récupérée. Pour val = 0 la valeur de retour est l'entier correspondant à 4 volts.

◆ dac_write()

void dac_write ( byte  ch,
int  cv 
)

Fonction d'écriture sur le bus SPI.

Build the 16-bit command word:
Bit 15: A/B (0 for MCP4921)
Bit 14: Buffered VREF (0 = unbuffered, 1 = buffered)
Bit 13: Output Gain (1 = 1x, 0 = 2x)
Bit 12: Shutdown control (1 = active operation)
Bits 11-0: 12-bit data value

Paramètres
chl'un des trois canaux
cvun entier entre 0 et 4095
